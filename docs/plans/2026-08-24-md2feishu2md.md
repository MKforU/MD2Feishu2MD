# md2feishu2md 实现计划

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** 构建 md2feishu2md 桌面应用——md↔飞书云文档双向转换，批量、指定目标路径、任务队列、pywebview UI、打包 exe + GitHub Release 发布。

**Architecture:** pywebview 桌面壳 + 原生 HTML/JS 前端；核心转换逻辑为纯函数（可单测），飞书 HTTP 调用集中在 feishu_api.py（含全局令牌桶限流 QPS≤3），任务队列做文档级并发。

**Tech Stack:** Python 3.11、pywebview、httpx、PyInstaller、pytest、原生 JS。

**参考实现：** `C:\Users\13555\.claude\skills\md-to-feishu-docx\scripts\md2feishu.py`（已验证的 md→飞书转换，含表格/行内格式/--dest），md2feishu.py 模块直接基于它改造。

## 阶段 2：飞书 API 封装

### Task 7: feishu_api.py — 凭据 + token + 限流器

**Objective:** 所有飞书 HTTP 调用的统一入口

**Files:**
- Create: `feishu_api.py`

**Step 1:** 写 `get_credentials()`（env 优先 → config.json 回退，桌面应用用 config.json）、`tenant_token()`。
**Step 2:** 写全局令牌桶 `RateLimiter(qps=3)`（`acquire()` 在每次请求前 await，令牌桶算法，默认 2.5 留余量）。所有 HTTP 方法统一过它。
**Step 3:** 写 `_request(method, url, ...)` 统一入口：限流 + 识别飞书限流错误（HTTP 400 + 限流错误码，如 `99991400`）→ 指数退避重试 3 次。
**验证:** 单测令牌桶（模拟 10 次请求 >3 秒）。

### Task 8: feishu_api.py — 文档/块/图片操作

**Objective:** 建文档、加块、图片三步、读块、删文档

**Files:**
- Modify: `feishu_api.py`

**Step 1:** `create_doc(title, folder_token=None)`、`add_children(doc_id, children)`、`create_table(doc_id, item)`（借鉴参考脚本 create_table）、`upload_images(doc_id, img_slots, md_dir)`（三步流程）、`read_blocks(doc_id)`（分页递归）、`download_image(file_token, save_path)`、`delete_doc(doc_id)`。
**Step 2:** 每个方法返回结构化结果，错误抛 `FeishuError(code, msg)`。
**验证:** 集成测试见 Task 9。

### Task 9: test_feishu_api.py — 集成测试（连飞书）

**Objective:** 批量转换调度

**Files:**
